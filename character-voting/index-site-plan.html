Character Name Voting Site Plan

Connor Steffenhagen

WDD 131-Online

Overview

Purpose

The purpose of this website is to engage the player community by allowing them to participate in the creative process of my game. It provides a platform where users can propose character names and vote on their favorites to determine the final names used in the game.

Audience

The primary audience includes fans of the upcoming game, beta testers, and indie game enthusiasts who enjoy community-driven development.

Dynamic elements

JavaScript will be used to handle the voting logic (preventing multiple votes per session), processing the form submission for new name suggestions, and dynamically updating the "Leaderboard" to reflect real-time vote counts and ranking changes.

Content

Home page

The home page will feature a "Vote Now" section containing a list of character cards. Each card will show a character's portrait, a list of current name candidates, and a "Vote" button. There will also be a "Suggest a Name" submission form at the bottom of the page.

Leaderboard Page

This page will feature a real-time ranked list of the top 10 most popular names. It will use a table format showing the Rank, Name, and Total Vote Count.
